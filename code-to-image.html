Does this tool run or highlight my code?

No. Code is treated as plain text and is not executed. The editor and PNG use a single text color rather than language-aware syntax highlighting. You can use snippets from any language.

What can I customize?

Choose a gradient, solid or transparent backdrop; change padding, title, window style, minimum width, font size and line numbers. Edit the code directly in the preview. Title and settings update the composition.

What is included in the PNG?

The current title, code and composition are rendered at 2× resolution. Each complete code line is included; long lines can make the export wider than the selected minimum width. Outputs are limited to 10,000 pixels per side and 25 million pixels total.

Can I copy the image instead of downloading?

Use Copy image where your browser permits PNG clipboard writing. Browser permissions and clipboard support vary. If copying fails, download the PNG and insert it into your document or presentation.

Where is my code processed?

Editing and image generation happen in your browser. This tool does not upload or execute your code. Keep a separate text copy: there is no automatic document save, and an exported image is not an editable source file.
