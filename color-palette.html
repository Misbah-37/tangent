Frequently Asked Questions
How does the tool find the dominant colors?

The extractor uses a local color quantization algorithm. It reads the raw image data, groups similar pixels into buckets, and identifies the most prominent color families to build a cohesive palette.

Does it work with any image format?

Yes, the tool fully supports standard web image formats including JPEG, PNG, and WebP files. High-resolution files are dynamically scaled down in-memory to ensure extraction is instantaneous.

Are my uploaded images saved or sent anywhere?

Absolutely not. True to the Tangent privacy philosophy, the image processing happens 100% inside your browser sandbox. We have zero access to your files.
