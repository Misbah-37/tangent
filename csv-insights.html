How CSV Insights Works

Local Processing

When you drop a CSV file, it is parsed instantly inside your browser's memory using JavaScript. We never upload your raw files to any server.

Automatic Profiling

The data dictionary automatically maps column types. We detect whether your columns contain text, numbers, or dates so you can build charts without setup.

Aggregations & Pivots

Build powerful summary views by selecting a dimension (X-Axis) and metric (Y-Axis). The chart builder handles grouping, sums, and averages on the fly.

Frequently Asked Questions

What is the maximum file size I can upload? +
Since everything runs locally in your browser's RAM, the maximum file size depends on your computer's memory. For most modern devices, CSV files up to 50MB will process instantly. If you need to analyze massive gigabyte-scale datasets, we recommend our SQL Analytics Studio which uses an optimized WebAssembly engine.
Is my sensitive financial data safe here? +
Yes. Absolutely zero data ever leaves your computer. The Tangent CSV Insights Studio uses an architecture called "Client-Side Processing". You can even turn off your internet connection after loading the page, and the tool will continue to work perfectly.
How does the Light Mode export work? +
When you export a chart using the "Light BG" option, the tool performs a split-second operation: it repaints the grid and text to dark colors, applies a solid white background, captures the screenshot, and then instantly reverts the live display back to Tangent's dark theme. This ensures your presentation slides look perfect without changing your viewing experience.
