How to extract your data

  1. Provide the source. Load a local HTML/text file or paste its markup. A live website URL is not fetched.
  2. Choose an approach. Detect tables, use a text selector, or choose Structured records and define a parent selector plus named fields. Attribute fields return literal values such as href.
  3. Inspect the result. Run extraction and browse 50-row pages. Check headers, merged cells and missing field values; edits to the source or rules invalidate the old result.
  4. Save the rows. Export the full extraction as CSV. Keep your source document for context and future corrections.

Source markup matters

Only content present in supplied HTML can be extracted. Website scripts are not run to populate missing content; this tool is not a browser crawler or OCR engine.

Which sources and extraction modes are supported?

Load one local .html, .htm or .txt source file up to 10 MiB, or paste HTML. Choose automatic tables, a single CSS text selector, or structured records with named fields. This tool does not fetch live URLs, execute website scripts, read PDFs or perform OCR.

How does structured extraction work?

Each parent-selector match becomes one record. Define up to 30 uniquely named fields using cleaned text or a literal attribute value. A field selector uses its first matching descendant (including direct-child selectors such as > .price; sibling selectors are unsupported); leave it blank to use the parent itself. Missing elements or attributes become blank cells. Links and other attributes are not opened, resolved or fetched.

How are table spans and multiple tables handled?

Rowspan and colspan repeat cell text across covered positions; rowspan zero is bounded to the current row group. Nested tables are extracted separately and removed from the containing cell text. Tables with identical, unambiguous explicit headers in the same order are combined, with a table identifier column for multiple sources. Different headers stay separately selectable and exportable. Headerless tables remain separate and receive generated column names, preserving their first data row. Leading header rows are combined into column labels; shorter rows are padded.

Does CSV export include every preview page?

Yes. Preview pages contain 50 data rows, excluding the first extracted header row from the data-row count. CSV includes the full extraction and header regardless of the page shown. Source or rule edits hide stale results until you extract again. Cleaned text and span expansion mean this is not a lossless markup copy.

Is supplied HTML executed, uploaded or saved?

Extraction parses a detached document and displays results as text rather than running supplied scripts or activating extracted attributes. Analysis is local; this page loads its CSV helper from this site. Work is not automatically saved and browser memory limits apply. Attribute values and source content remain untrusted data; review exports before sharing or using elsewhere.
