How to Use

  1. Download & Extract: Extract the File_Organizer.zip folder anywhere on your PC.
  2. Launch: Open the extracted folder and double-click file_organizer.exe.
  3. Select Directory: Click Browse to choose your messy folder (e.g., Downloads or Desktop).
  4. Organize: Click Organize! and watch your files get structured in seconds.

Frequently Asked Questions
Can the organizer accidentally delete or overwrite my files?

No. The sorting engine uses non-destructive moves. If a file with an identical name exists in the target folder, the system safely renames the incoming file rather than overwriting.

Does the browser have permanent access to my disk?

No. The browser's File System Access API requires your explicit permission each time you select a directory. Permissions are automatically revoked when the tab closes.

How do I run the Python organizer script locally?

Download File_Organizer.zip, extract the files, and run 'python organize.py'. It requires zero external pip dependencies and runs instantly on Windows, macOS, or Linux.
