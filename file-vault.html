Frequently Asked Questions
Can anyone (including Tangent) decrypt my files without the password?

No. The encryption key is derived directly from your password using PBKDF2 with 100,000 iterations and AES-GCM 256-bit cryptography. Without the password, mathematical decryption is virtually impossible.

What encryption standard does File Vault use?

It uses Web Crypto API authenticated AES-GCM (Galois/Counter Mode) with 256-bit keys and cryptographic random initialization vectors (IV) for every encryption pass.

Can I decrypt my vault offline on another computer?

Yes. Because File Vault uses open web cryptography standards, you can open Tangent on any computer (even offline) and unlock your files instantly.
