What does this tool convert?

Load HEIC or HEIF files to create JPEG copies. This tool exports a still image; it does not preserve Live Photo motion, bursts or animations. Decoder support varies between files. Keep your originals.

How do I choose JPEG quality?

Set quality before loading a batch. Higher values generally preserve more detail and produce larger files. The setting is captured when conversion starts; changing it later does not update existing results. Reload the files to convert them with a different setting.

Can I download several photos together?

Yes. Each successful conversion has an individual JPEG download. Download ZIP collects successful results with distinct filenames. A new file selection replaces the current batch; save the results before replacing or clearing it.

Are my photos uploaded?

Decoding and conversion run in your browser. Decoder, ZIP and download libraries load from external CDNs. The tool does not upload your photos. Camera metadata is not copied to the JPEG; review the converted appearance and keep the source files.

What are the limits?

Use files up to 50 MiB each and batches up to 100 MiB. Converted images are checked against 10,000 pixels per side and 25 million pixels total. Decoder memory use can impose lower practical limits, and unsupported or damaged files can fail while other files succeed.
