PRIVACY, WITH CLARITY

Your work belongs to you.

Local file processing happens on your device. Browser tools need memory and processing time, and some download libraries or AI models before they are ready.

Tools that fetch a URL or check a breach database make network requests. Any selected network operation has its own requirements; local processing does not mean every tool works offline.

Can I use the tools without an account?

The browser tools are free to use without an account. Practical file sizes and processing times depend on your device and browser.

What does Password Shield send?

Strength analysis stays local. The optional breach check sends a 5-character SHA-1 prefix to Have I Been Pwned after you request the check. The service can also see your IP address.

Will every tool work offline?

Offline availability varies. Let required libraries and models finish downloading before disconnecting. Browser caches can be evicted, and reopening a page offline is not guaranteed.
