Before you begin.

A few useful answers.

Tools for data, documents and everyday work.

What can I do with RunTangent?

Explore browser tools for data cleaning and analysis, PDF and document tasks, image editing, audio and video, design graphics, security, business documents and everyday utilities. Browse the complete toolkit to find a tool for your task.

Can I use the tools without an account?

The browser tools are free to use without an account. Practical file sizes and processing times depend on your device and browser.

Do my files stay on my device?

Local file processing happens on your device. Some tools download libraries or models, and features that fetch a URL or check a breach database make network requests. Each tool explains its own requirements.

What does Password Shield send?

Strength analysis stays local. The optional breach check sends a 5-character SHA-1 prefix to Have I Been Pwned after you request the check. The service can also see your IP address.

Will every tool work offline?

Offline availability varies. Let required libraries and models finish downloading before disconnecting. Browser caches can be evicted, and reopening a page offline is not guaranteed.

What is RunTangent Analyst?

RunTangent Analyst is a Windows desktop workspace for preparing, exploring and querying local data. Its first free Microsoft Store release is currently in certification.
