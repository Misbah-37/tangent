How to shape your document

  1. Choose a starting point. Start from a template or a blank page. Loading a preset replaces the draft after confirmation.
  2. Write and structure. Use headings, lists, tables, code and LaTeX equations.
  3. Read the typeset version. Check the live preview and choose its typography. Save a local draft only if you want one.
  4. Export with care. Keep the Markdown source, export HTML, or open Print / PDF and review final pagination.

What can I write here?

Write Markdown headings, lists, tables and code, with inline or block LaTeX equations rendered using KaTeX. Start from a research paper, engineering RFC, math template or a blank document. Review supported syntax in the preview.

How do I export my document?

Download raw Markdown or formatted HTML. Print / PDF opens the browser print workflow, where Save as PDF may be available. Pagination and print settings depend on the browser; inspect the result before sharing.

Is my draft saved automatically?

Draft saving is off by default. Enable Save draft on this browser to store a local draft. Turning it off removes that stored draft. Export important work before clearing browser data or closing the page.

Can I include HTML, remote images and citations?

Active HTML and automatic remote images are omitted from the preview. This is not a reference manager or citation-style engine. Review links, equations and formatting in the export.

Where does processing happen, and are there limits?

Editing and rendering run in your browser. Libraries and math fonts may load from external CDNs. Formatted rendering is limited to 500,000 characters. Local draft storage and print layout depend on your browser.
