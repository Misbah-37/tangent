How to redact a PDF

  1. Open your document. Load a PDF and find the pages you need.
  2. Mark the areas. Draw boxes over the complete sensitive area, leaving a small margin.
  3. Review each page. Move or resize the selections and undo changes as needed. Check for information outside your boxes.
  4. Apply and inspect. Download a separate image-based PDF. Reopen it and review every page before sharing.

A different kind of PDF

Export rebuilds every page as an image. Searchable text and editable forms are lost; image quality and file size can change. Keep your original. Marking a box in this workspace has not yet changed any file.

Does this only cover the original text?

The exporter renders every page, paints the marked areas into that image and creates a new image-based PDF. Original text objects are not copied into that result. Inspect your downloaded copy before sharing.

What changes in the exported PDF?

Every page becomes an image. Selectable text, editable forms, links, annotations and existing digital signatures are not preserved as interactive document features. Rasterization can affect quality and file size.

Can I change a selection before downloading?

Yes. Draw boxes, select them to move or resize them, and use Undo, Redo or Delete before applying. Your source PDF is unchanged; the download is a separate copy.

What does the document information option do?

The exporter creates a new PDF rather than copying the source document structure. With this option enabled it also omits the output Info dictionary and XMP metadata. This is not a certification that all sensitive visible information has been found.

Where does processing happen?

Selected document contents are processed in browser memory. PDF libraries load from external CDNs, so network access may be required. Large documents depend on your device memory. Keep the original and review every output page.
