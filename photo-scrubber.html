    How to clean a photo

    1. Open the original. Load a JPEG, PNG or WebP, or add photos in Batch.
    2. Read the details. Review the supported metadata. An empty field is not a complete privacy assessment.
    3. Create your copy. Choose an output format for a single photo, or process the batch.
    4. Review and save. Download the new file or ZIP, inspect the image and retain your originals.

    What does the cleaned copy remove?

    The tool redraws decoded image pixels into a new file without copying source EXIF or GPS tags. The browser may add its own format or color information. This is not a guarantee that every possible identifier has been removed.

    Does the inspector show all metadata?

    No. It displays supported EXIF fields such as camera, date and GPS tags. Missing fields mean the inspector did not find them; other metadata may still exist. The inspector is not a complete metadata inventory.

    Will my photo look exactly the same?

    Dimensions are retained, but JPEG and WebP re-encoding can affect detail and color. PNG preserves decoded pixels. JPEG fills transparency with white. Review orientation and appearance in the downloaded file.

    Can I clean several photos together?

    Use Batch to queue images and create a ZIP of new copies. Each file is decoded and re-encoded in the browser. Large images and queues depend on available memory; keep the originals and review the exported files.

    Where are my images processed?

    Processing runs in your browser. Libraries may load from external CDNs. Opening the optional map link sends coordinates to OpenStreetMap. There is no automatic image archive; download results before clearing the workspace.
