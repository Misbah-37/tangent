Frequently Asked Questions
Is there a file size limit for bulk processing?

Because processing happens entirely on your local machine, there are no artificial cloud limits. You are only limited by your device's available RAM and processing power.

Does the watermarker degrade my image quality?

The tool is optimized to export JPEG and WebP files at 92% quality, which perfectly preserves visual sharpness while keeping file sizes lightweight and web-ready.

Can I upload a custom image or logo as my watermark?

Currently, the tool supports highly customizable text-based copyright stamping (allowing you to control text, size, color, opacity, and position). Image-based logo stamping is planned for a future update.
