Frequently Asked Questions
Are my academic manuscripts or papers uploaded to any server?

No. Markdown & Academic Document Studio runs completely in your local browser memory using client-side JavaScript and Web APIs. Your text, formulas, and data never leave your device.

Does it support LaTeX math equations?

Yes. Inline math can be enclosed between single dollar signs ($E = mc^2$), while standalone block equations use double dollar signs. All formulas render instantly via KaTeX.

Can I export formatted PDFs without browser headers and footers?

Yes. Clicking 'Export PDF' opens a print-optimized window that strips URL stamps and browser chrome, producing clean publication-ready PDFs.
