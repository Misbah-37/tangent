Frequently Asked Questions
Why does the image process in my browser instead of a server?

Processing images locally (client-side) is significantly faster and 100% secure. You don't have to wait for large files to upload or download, and you never have to worry about your personal photos being stored on a third-party server.

What is the difference between resizing and compressing?

Resizing alters the actual pixel dimensions (width and height) of the image, while compressing reduces the file size (bytes) by optimizing color data and discarding redundant metadata without changing physical dimensions.

How do I ensure my images meet strict upload size requirements?

Use the Target File Size mode, enter your desired file size in KB (e.g., 200 KB), and the engine will automatically run a binary search compression algorithm to find the optimal quality setting.
