Frequently Asked Questions
Is there any recording time limit or video cap?

Recording stops at 30 minutes or approximately 256 MB per clip to limit browser memory use. Save each clip before starting another or leaving the page.

Can I record system audio along with microphone sound?

System audio depends on the browser and selected screen or tab. Enable 'Share audio' in the browser picker when available. Microphone permission is requested only when you start a recording.

Where are my recorded video files stored?

Recordings are saved directly to your device's Downloads directory upon stopping. The tool never uploads or caches video bytes on remote servers.
