Frequently Asked Questions
Are my SVG graphics or logo files uploaded anywhere?

No. All parsing, XML sanitization, coordinate rounding, and minification happen entirely inside your browser memory using native DOMParser and regex engines. No files are transmitted across any network.

What hidden metadata does the optimizer remove?

It safely strips Adobe Illustrator, Inkscape, Sketch, and Figma generator tags, XML namespaces, doctypes, comments, and empty group tags while keeping paths and vector curves intact.

Can I rasterize optimized SVGs to PNG images?

Yes. The tool features a built-in high-DPI rasterizer that converts your cleaned SVG directly into a transparent PNG for presentation decks and apps.
