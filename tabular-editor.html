Editing & export behavior notes

Edit cells directly. Enter commits, Escape cancels, Tab moves focus. Undo preserves imported-record identities; row numbers exclude skipped blank CSV/TSV records and are not worksheet row numbers. Choose text or numeric sorting. Blank and nonnumeric values sort last in numeric mode. Edits keep the view order until refreshed.

JSON export preserves unchanged value types and absent fields. Edited cells export as text; nested objects and arrays display as JSON text. CSV and TSV exports contain text values. Excel uses cached formula results, not formulas; dates export as ISO text. XLSX downloads contain one values-only sheet, without original styles or other sheets.

Tabular Editor is a browser tabular editor for checking values, making targeted corrections and exporting an edited dataset. Keep your source row identities while you inspect different views.

How to edit a dataset

  1. Open your file. Load CSV or TSV with unique headers, choose an Excel worksheet, or open a JSON array of records. Your data stays in browser memory.
  2. Make a focused correction. Click a cell, position the cursor and edit. Commit with Enter or cancel with Escape. Undo and Redo help you revisit decisions.
  3. Find the rows you need. Search across columns, choose a text or numeric sort and inspect the paginated table. Expand it when you need more room.
  4. Choose what to keep. Export all rows or the filtered/sorted view. Download your edits before closing or replacing the dataset.

Built around careful editing

A cursor, not a reset

Edit individual characters without automatically selecting the whole cell. Text values and leading zeros remain text.

A dependable view

Search, apply column filters, sort as text or numbers, and paginate without deleting hidden rows. Source row numbers preserve each record’s identity as the view changes.

An explicit export

Choose the full dataset or your current view. Downloads include every matching row across pages, with committed edits preserved.

Local work needs a saved result

Editing is local to this page, not automatically saved to disk. Keep the original file and download your result. Device memory limits apply; this browser version supports CSV, TSV, XLSX and JSON records, with text/numeric sorting and more Pro capabilities planned.

Which formats can I edit, and what does Excel preserve?

Open CSV, TSV, XLSX or a nonempty JSON array of records. For CSV/TSV, choose the header record and skip introductory records; blank records are excluded from numbering. For Excel, select one worksheet. Formula cells use stored results, not recalculation; missing results are blank. Dates become ISO text. XLSX exports create a values-only sheet without original formulas or styling. Unchanged JSON/Excel types are retained where supported; edited cells become strings. Keep large identifiers as text.

How do editing, undo and keyboard navigation work?

Click a cell to place the cursor without selecting all its text. Enter commits, Escape cancels, and Shift+Enter adds a line break. Optional Spreadsheet navigation uses arrows between cells and Enter/F2 to edit; editing keys then operate on text normally. Undo/Redo retains up to 1,000 committed edits. Drag a header edge or focus its resize handle and use Left/Right to adjust column width. Escape cancels a cell edit without closing expanded view.

Do filters or sorting change the dataset, and what gets exported?

Filters only change the view. Column filters combine with AND, and empty means blank or whitespace-only; N/A remains a value. Choose text or numeric sorting, with blank/nonnumeric values last in numeric mode. Refresh the view after edits to reapply its rules. Find matches and jump by view row across pages. All rows exports the dataset in imported order; Filtered / sorted view exports every matching row across all pages, not just the visible page.

Where is my data processed, and are there size limits?

Parsing and editing happen in browser memory; uploaded file contents are not sent to a processing server. Website assets and libraries may require network requests, so offline availability is not guaranteed. Capacity depends on browser/device memory. The grid displays 100 rows per page but keeps the dataset in memory. Excel extraction limits used ranges to 2,000,000 cells; parsing still uses memory. No unlimited-size or fixed-speed guarantee is made.

How do I keep edits before closing or replacing a file?

Download data creates a separate file; it does not modify the original. A full-dataset download records a checkpoint but cannot confirm the browser saved it, so check your downloads. Filtered-view exports do not checkpoint the whole dataset. Edits since the checkpoint trigger a discard confirmation on close or replacement. Cancelling preserves the dataset. Highlights still compare against the imported original, and undo history is not a persistent backup.
